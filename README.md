# 🎯 Target Number Game

A simple Python game where the player tries to reach a randomly generated target number.

## 🎮 How to Play

* The computer generates a target number.
* Enter numbers to reach the target.
* Keep trying until you reach the target number.
* The game displays the result when you win.

## 🛠️ Concepts Used

* Python
* `random`
* User input
* Conditional statements
* Loops
* Variables
